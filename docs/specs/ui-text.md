# リザーブマシン — UI設計（テキスト版）

| 項目 | 内容 |
| --- | --- |
| 作成日 | 2026年9月13日 |
| 基準 | 正式仕様 `mvp-spec.md`（第4章 全体の流れ、第5章 機能一覧、第7章 画面一覧） |
| 位置付け | 画面の配置・文言・状態をテキストで描いた設計図。見た目の色やフォントは実装時に決める |

## 0. 読み方

### 0.1 記号

| 記号 | 意味 |
| --- | --- |
| `[ 次へ ▶ ]` | 主ボタン（1画面に1つ） |
| `( あとで )` | 副ボタン |
| `‹ 戻る` | 前の画面へ戻るリンク |
| `［__________］` | 文字の入力欄 |
| `［ 9月19日(土) ▼ ］` | 選択欄 |
| `(●)` `( )` | 1つだけ選ぶ選択肢 |
| `[✓]` `[ ]` | 複数選べる選択肢 |
| `〈仮〉` `〈AIの推定〉` | ラベル。出どころや状態を表す |
| `▓ サンプル ▓` | 画面上部に固定する帯 |
| `…` | 省略 |

### 0.2 画面の描き方

- スマホ幅360pxを基準に描く。PCでは中央に最大幅480pxで同じ配置にする。
- 日本語は等幅フォントでも幅がそろわないため、枠の右側は描かない。
- 例に出てくる人物・金額・日時は、すべてデモ用の架空の値。

## 1. 共通の部品

### 1.1 ヘッダー

```text
┌─────────────────────────────
│ ‹ 戻る     リザーブマシン     ⚙
└─────────────────────────────
```

- 左：戻る。入口・ホームでは出さない。
- 右：設定（S-17）。
- 質問など手順がある画面は、タイトルの下に進み具合を出す。

```text
│ 質問 2 / 6   ●●○○○○
```

### 1.2 帯（画面上部に固定）

同時に出る場合は上から次の順に重ねる。

```text
▓ 構想デモ（実際のデータではありません） ▓
▓ デモ用のデータで表示しています ▓
▓ サンプル：この機能は固定の例を表示しています ▓
▓ この端末に保存できませんでした ▓
```

| 帯 | 出す条件 | 出典 |
| --- | --- | --- |
| 構想デモ | G-01〜G-03 | 正式仕様 §7 |
| デモ用 | デモデータを読み込んでいる間、全画面 | 正式仕様 §9 |
| サンプル | その画面の機能モードが「モック」 | 正式仕様 §1.2 |
| 保存失敗 | 端末への保存に失敗したとき | F-26 |

### 1.3 下のナビゲーション

ホーム・ツリー・履歴・設定の4画面にだけ出す。入口から予約までの手順の途中では出さない。

```text
├─────────────────────────────
│  🏠ホーム   🌳ツリー   🕘履歴   ⚙設定
└─────────────────────────────
```

### 1.4 出どころのラベル

数字の横に必ず付ける。押すと説明が開く。

```text
月額 1万円 〈AIの推定〉
週の時間 9時間 〈本人の回答〉
1ヶ月の支出 ◯万円 〈統計の参照値 ⓘ〉
使える時間 3時間 〈本人の回答〉〈仮〉
年52日 〈制度からの計算〉
```

統計の参照値を押したとき：

```text
┌─────────────────────────────
│ 統計の参照値
│ 総務省「家計調査」
│ 対象：（転記した区分）
│ 調査年：（転記した年）
│ 資料を開く ↗
│                  ( 閉じる )
└─────────────────────────────
```

### 1.5 行動の状態ラベル

色だけで区別せず、必ず文字を出す。

| ラベル | 状態 |
| --- | --- |
| `〈日時未設定〉` | 日時を決めていない |
| `〈日時確定・未登録〉` | 日時は決めたが、カレンダーに入れていない |
| `〈登録済み〉` | カレンダーに入ったことを確認した |
| `〈確認待ち〉` | 終了時刻を過ぎて、結果を記録していない |
| `〈できた〉` `〈少しできた〉` `〈できなかった〉` | 記録済み |
| `〈見送り〉` | 見送った |
| `〈最初の1日〉` | 今週いちばん早い行動の印 |

### 1.6 処理中

```text
┌─────────────────────────────
│
│        ◌  10年後の生活を考えています
│           少し時間がかかります
│
└─────────────────────────────
```

- 処理中は送信ボタンを押せない（F-28）。
- 文言は処理ごとに変える：「質問を考えています」「体験の候補を探しています」「10年後の生活を考えています」「次の一歩を考えています」「来週の計画を考えています」。

### 1.7 AIの失敗

```text
┌─────────────────────────────
│ ⚠ うまく作れませんでした
│ 入力した内容は残っています。
│
│ [ もう一度試す ]
│ ( 入力に戻る )
└─────────────────────────────
```

- 自動で1回だけ再試行したあとに出す（F-28）。
- 失敗した結果の一部を表示しない。

## 2. 画面の流れ

```text
S-01 空白の提示
  └→ S-02 入口
       ├→ S-03 願いの入力 ────────────┐
       ├→ S-04 明日の過ごし方 → S-05 体験候補 ─┤
       └→ G-01 構想デモ：記録から関心 ───┤
                                      ↓
                              S-06 質問
                                      ↓
                              S-07 10年後の生活と値札
                                      ↓
                              S-08 逆算ツリー
                                      ↓
                              S-09 日時決定
                                      ↓
                              S-10 予約票
                                      ↓
                              S-11 カレンダー登録
                                      ↓
                              S-12 ホーム ←──────────┐
                               │  │  │               │
                               │  │  └→ G-02 自動で記録 │
                               │  └→ S-15 次の1週間 → S-09
                               └→ S-13 振り返り → S-14 次の一歩
                                                 ├ 承認 → S-09
                                                 └ 保留 → S-12
```

- 保存済みのデータがあれば、起動時は S-12 ホームを開く。
- S-14 の「別の案」に G-03 構想デモの案が並ぶ。
- 強い苦痛を示す入力があった場合は、どの画面からでも S-18 に切り替わる。

## 3. 入口と発見

### S-01 空白の提示

対応機能：F-02　出典：C案

```text
┌─────────────────────────────
│               リザーブマシン     ⚙
├─────────────────────────────
│
│ あなたの時間に、
│ これから空白が来ます。
│
│ どんな変化がありましたか？
│ (●) 週休3日になった
│ ( ) AIで仕事が減った
│ ( ) 定年を迎える
│ ( ) 就活が終わった
│ ( ) その他
│
├─────────────────────────────
│ 1年で   52日      〈制度からの計算〉
│ 10年で  520日
│         4,160時間  ※1日8時間で計算
├─────────────────────────────
│
│ この時間で、何をしていたいですか？
│
│ [ 考えてみる ▶ ]
│ ( あとで見る )
└─────────────────────────────
```

「週休3日」以外を選んだとき：

```text
│ ( ) AIで仕事が減った    (●)
│
│ 1週間に増えた自由な時間は？
│ ［ 5 ］時間
│
│ 1年で   260時間     〈本人の回答〉
│ 10年で  2,600時間
```

| 操作 | 動き |
| --- | --- |
| 選択肢を変える | 下の数字がその場で変わる |
| 考えてみる | S-02 へ |
| あとで見る | S-02 へ。空白は記録しない |

エラー：時間が0以下か168を超える場合「0より大きく168以下で入力してください」。

```text
├─────────────────────────────
│
│ 試せる体験を3つ見つけました。
│ まず1回、試すものを選んでください。
│
│ ┌───────────────────────────
│ │ (●) 近所を歩いて写真を1枚撮る

│ │       負担なく応えられます
│ │ 最初に試すこと：10分歩いて
│ │   気になったものを1枚撮る
│ │ ⏱ 10分   💴 0円 〈AIの推定〉
│ └───────────────────────────
│ ┌───────────────────────────
│ │ ( ) 陶芸体験の空きを調べる
│ │ 理由：「何か作る」に近い体験です
│ │ 最初に試すこと：近くの体験教室を
│ │   3つ書き出す
│ │ ⏱ 20分   💴 0円 〈AIの推定〉
│ └───────────────────────────
│ ┌───────────────────────────
│ │ ( ) 好きな飲み物をゆっくり淹れる
│ │ …
│ └───────────────────────────
│
```

| 操作 | 動き |
| --- | --- |
| これにする | 選んだ体験を「願い」として S-06 へ |

- 何も選んでいないときは「これにする」を押せない。
- AIが好みを断定する文言は出さない（A案 §3）。

### S-06 質問

対応機能：F-06　出典：B案・A案・C案

AIが作る質問（最大5問）と、固定質問5問を1問ずつ出す。

```text
┌─────────────────────────────
│ ‹ 戻る     質問 2 / 8   ●●○○○○○○
├─────────────────────────────
│
│ 休日に、自分のために使える時間は
│ どれくらいですか？
│
│ ⓘ 1回の活動時間を決めるために使います
│
│ ( ) 1時間未満
│ (●) 1〜3時間
│ ( ) 3時間以上
│ ( ) 分からない
│
│ [ 次へ ▶ ]
└─────────────────────────────
```

数値で答える質問：

```text
│ 月に使える費用はどれくらいですか？
│
│ ［ 10000 ］円
│ [ ] 分からない
```

使える曜日と時間帯（固定質問）：

```text
│ 予定を入れられる時間帯を
│ すべて選んでください。
│
│ [ ] 平日の夜（19〜22時）
│ [✓] 休日の午前（9〜12時）
│ [✓] 休日の午後（13〜18時）
│ [ ] 休日の夜（19〜22時）
```

C案の固定質問：

```text
│ この半年で、頼まれてもいないのに
│ 時間を使ったことはありますか？
│
│ [ ] 動画を見る  [✓] 料理  [ ] 運動
│ [✓] ものを作る  [ ] 読書  [ ] ゲーム
│ その他 ［__________］
│ [ ] 特にない
```

- 「分からない」を選んだ項目は、次の画面で〈仮〉が付く。
- 最後の質問の「次へ」で、10年後の生活とツリーを作る（処理中）→ S-07。

## 4. 10年後と逆算

### S-07 10年後の生活と値札

対応機能：F-07、F-10　出典：C案

```text
┌─────────────────────────────
│ ‹ 戻る     10年後の生活
├─────────────────────────────
│
│ 空白の4,160時間で、
│
│ ╭───────────────────────────
│ │ 🏺 週3日、陶芸をしている
│ ╰───────────────────────────
│                        〈AIの推定〉
│
│ この生活の値札
│ ┌───────────────────────────
│ │ 初期費用   5万円   〈AIの推定〉  ✏
│ │ 月額       1万円   〈AIの推定〉  ✏
│ │ 週の時間   9時間   〈本人の回答〉 ✏
│ │           3時間 × 週3日
│ └───────────────────────────
│ ※目安です。実際の費用は確かめて
│   ください。利回りや税は含みません。
│
│ ▼ この金額の根拠
│
│ [ ここから逆算する ▶ ]
│ ( 別の生活を考える )
└─────────────────────────────
```

✏ を押したとき：

```text
│ 月額
│ ［ 8000 ］円
│ [ 保存 ]  ( やめる )
│
│ → 保存後：月額 8,000円 〈本人の回答〉
```

| 操作 | 動き |
| --- | --- |
| ✏ | その項目を編集。保存すると出どころが「本人の回答」になる（F-12） |
| この金額の根拠 | AIが出した理由を開く |
| ここから逆算する | S-08 へ |
| 別の生活を考える | 同じ回答で作り直す（処理中） |

エラー：金額が0未満は「0以上で入力してください」。週の時間が0以下か168を超える場合も同様に出す。

対応機能：F-08〜F-13　出典：B案

```text
┌─────────────────────────────
│ ‹ 戻る     逆算ツリー
├─────────────────────────────
│
│ 💭 願い
│ なんか、このままじゃまずい気がする
│ 自分の理由：〈未回答〉 ✏
│  │
│ 🏺 10年後の生活
│ 週3日、陶芸をしている
│  │
│ 🎯 3年後（2029年9月） ✏
│ 小さな作品展に出す
│  │
│ 🎯 1年後（2027年9月） ✏
│ 人に見せられる作品を1つ持つ
│  │
│ 🔢 数字
│ ┌───────────────────────────
│ │ 月あたりの時間  月6時間
│ │ 3時間 × 月2回 ＝ 月6時間
│ │ 〈本人の回答〉〈仮〉 ✏
│ ├───────────────────────────
│ │ 値札  初期5万円／月1万円／週9時間
│ │ 〈AIの推定〉 ✏
│ └───────────────────────────
│  │
│ 📅 今月の行動
│ ・体験教室に1回行く
│ ・近くの教室と道具を調べる
│  │
│ ✅ 今週の行動
│ ┌───────────────────────────
│ │ ① 陶芸体験の空きを調べる
│ │    30分 〈最初の1日〉〈日時未設定〉
│ ├───────────────────────────
│ │ ② 教室の作品写真を見る
│ │    15分 〈日時未設定〉
│ ├───────────────────────────
│ │ ③ 道具の値段を調べる
│ │    20分 〈日時未設定〉
│ └───────────────────────────
│
│ [ 日時を決める ▶ ]
│ ( 行動を作り直す )
└─────────────────────────────
│  🏠ホーム   🌳ツリー   🕘履歴   ⚙設定
```

お金の願いの場合、数字の欄は次のようになる。

```text
│ 🔢 数字
│ ┌───────────────────────────
│ │ 毎月の積立額  月2.7万円
│ │ (480万円 − 60万円) ÷ 156ヶ月
│ │ 生活の月額 20万円 〈統計の参照値 ⓘ〉〈仮〉
│ │ 現在の貯金 60万円 〈本人の回答〉
│ │ ※利回りや税は含めていない目安です
│ └───────────────────────────
```

| 操作 | 動き |
| --- | --- |
| ✏（期限・数字） | 編集するとその場で数字を再計算する。行動は変わらない（F-12） |
| ✏（理由） | 自分の理由を入力。空欄のままでよい（F-13） |
| 日時を決める | S-09 へ |
| 行動を作り直す | 確認ダイアログ（§8.1）→ 日時未設定の行動だけ作り直す |

- 数字の入力が足りないときは、結果の代わりに「入力が必要です」を出す。
- すでに目標額に届いている場合は「すでに目標額に届いています」。

### S-09 日時決定

対応機能：F-14　出典：A案・B案

```text
┌─────────────────────────────

├─────────────────────────────
│
```

```text
┌─────────────────────────────

│
```

```text
│ 置き換わります。
│ カレンダーに入れた行動は残ります。
│
│ [ 作り直す ]   ( やめる )
└─────────────────────────────
```

### 8.2 すべての記録を削除

```text
┌─────────────────────────────
│ すべての記録を削除しますか？
│
│ 願い・ツリー・予定・振り返り・履歴が
│ この端末から消えます。元に戻せません。
│
│ Googleカレンダーに入れた予定は
│ 消えません。

```

- 「新しい願いから始める」も同じ形で、「今の願いと記録は置き換わります」と出す（F-27）。

### 8.3 行動の詳細メニュー

```text
┌─────────────────────────────
│ 教室の作品写真を見る
│ 9月20日(日) 10:00〜10:15 〈登録済み〉
│
│ ( 予約票を開く )
│ ( 記録する )
│ ( 日時を変更 )
│ ( 見送る )
│ ( カレンダーで見る ↗ )
│ ( 閉じる )
└─────────────────────────────
```

見送るとき（自動で登録した予定の場合）：

```text
┌─────────────────────────────
│ 見送りにしました。
│ カレンダーの予定も削除しますか？
│
│ [ 削除する ]   ( カレンダーは残す )
└─────────────────────────────
```

カレンダーで開く・予定ファイルで入れた予定の場合：

```text
│ 見送りにしました。
│ カレンダーの予定は、カレンダーの
│ 画面から消してください。
│ ( カレンダーで見る ↗ )  ( 閉じる )
```

### 8.4 デモの人物を選ぶ

```text
┌─────────────────────────────
│ デモを見る
│
│ ( ) 佐藤さん 48歳
│     何をしたいか分からない
│ (●) けんたさん 32歳
│     このままじゃまずい気がする
│ ( ) 週休3日になった会社員
│     空白の使い道を探している
│
│ 状態
│ ［ 予約前 ▼ ］
│   予約前／確認待ち／記録後／次週
│
│ ※いまの記録はデモの間は表示されず、
│   終了すると元に戻ります。
│
│ [ デモを始める ]   ( やめる )
└─────────────────────────────
```

- デモの間は全画面に「デモ用」の帯を出す。
- 設定に「デモを終わる」を出す。

### 8.5 保存データを読み込めない

```text
┌─────────────────────────────
│ データを読み込めませんでした
│
│ 保存されている記録の形式が
│ 読み取れませんでした。
│
│ [ 最初からやり直す ]
│ ( 記録を削除する )
└─────────────────────────────
```

- 読み込めなかったデータは、どちらかを選ぶまで上書きしない。

## 9. 構想デモ

3画面とも、画面上部に「構想デモ（実際のデータではありません）」の帯を固定する。承認した結果は、デモデータにだけ書き込む。

### G-01 記録から関心を見つける

対応機能：F-37　出典：C案 v0.2

```text
▓ 構想デモ（実際のデータではありません） ▓
┌─────────────────────────────
│ ‹ 戻る     記録から見つける
├─────────────────────────────
│
│ 将来は、あなたが選んだ記録から、
│ 言葉にしていない関心を見つけます。
│
│ 例：半年間の動画の視聴（サンプル）
│ ┌───────────────────────────
│ │ 陶芸・ろくろの動画      42本
│ │ キャンプ料理            18本
│ │ 古い家の改修            11本
│ └───────────────────────────
│ ※端末の中で集計し、AIには上位の
│   件数だけを送る想定です。
│
│ 頼まれてもいないのに見ているもの
│ ╭───────────────────────────
│ │ (●) 手を動かして何かを作ること
│ │     根拠：陶芸の動画を42本
│ │ ( ) 外で過ごす時間
│ │     根拠：キャンプ料理の動画を18本
│ │ ( ) 住まいを自分で整えること
│ │     根拠：改修の動画を11本
│ ╰───────────────────────────
│
│ [ これを願いにして進む ▶ ]
└─────────────────────────────
```

- 「これを願いにして進む」で S-06 質問に合流する。ここから先はデモの帯を外す。

## 10. 文言のルール

正式仕様 §14.1 と B案 §13 に合わせる。

| 場面 | 使う | 使わない |
| --- | --- | --- |
| できなかった記録 | 記録してくれてありがとうございます。次は小さく始めましょう | サボった、失敗、ダメ |
| 休む選択 | 今日は休むのも選べます | 休んでばかり |
| 結果の見通し | 目安です、たとえば | 必ず叶う、確実に増える |
| 行動のすすめ | やってみませんか、〜だけでもOK | やらなければならない |
| 人について | （評価しない） | 不要、堕落、怠け、負け組 |
| 予約 | あなたの予定です | 申し込みました、予約が取れました |

- ボタンは動詞で終える（「記録する」「日時を決める」）。
- 数字には単位と出どころを必ず付ける。
