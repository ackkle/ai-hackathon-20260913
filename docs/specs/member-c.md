# リザーブ・マシン 要件定義書 v0.1

## 1. 一文で

自分で選んだわけではない空白が降ってくる人に、本人が意図せず残した記録から「実はもう興味を持っている未来」を見つけ、時間とお金の値札をつけて予約させるアプリ。

## 2. 背景・前提

- 10年後、稼ぐこと・働くことの多くをAIが代わりに行う
- 浮いた時間の使い方を、多くの人は決められない
- 週休3日制の導入企業では、この問題はすでに起きている

## 3. 審査観点との対応

| 観点 | 一言 |
|---|---|
| 価値 | 稼ぐことをAIがやる世界で、浮いた時間を何に使うか決められない人のためのもの |
| 実現性 | 手元にある記録（履歴・カレンダー・チャット）だけを入力にするので今日動く。週休3日の会社ではすでに起きている問題 |
| 新規性 | 願望を聞かない。記録から本人が言葉にしていない未来を先に見せ、計画ではなく「予約」として時間とお金を確保させる |
| AIの活かし方 | 記録の羅列 → 関心の抽出 → 10年後の具体的な生活と値札への翻訳。AI以外では成立しない |
| 展開性 | AIが労働を代替する速度に比例して対象者が増える。今は一部、10年後は全員 |

## 4. ターゲット

### 4.1 定義

外から空白が降ってくる人。やる気がないのではなく、やる気を仕事に吸われていて、空白を感じたことがない。だから空白が来ることが少し怖い。

| 空白の降り方 | 具体像 | 位置づけ |
|---|---|---|
| AIが仕事を減らす | 30代エンジニア | 主ペルソナ（デモ） |
| 会社が週休3日にする | 増えた1日の使い方が分からない会社員 | 実現性の根拠 |
| 定年が来る | 10年後の60代＝今の50代 | 展開性 |
| 就活が終わる | やることのない大学生 | 展開性 |

### 4.2 主ペルソナ

**亀野ながれ（35）**
都内在住。通信系企業でR&Dエンジニア。副業でAIによる管理規約書類の自動化を1人で回す。実家はやきとり屋。

- 副業の自動化が進み、1件の手作業は3時間→40分に。空いた時間は次の自動化とハッカソンに消える
- 週末はランニングとスマホ。YouTube履歴に「頼まれてもいないのに見ている動画」があるが、それを関心だと思っていない
- 先週、会社が週休3日制の試験導入を発表。増えた1日で何をするか思いつかなかった
- 10年後は45歳。副業も本業の一部もAIがやる。実家を継ぐか聞かれるが、答えはない

**アプリを開く瞬間**
発表の翌週、日曜の夜。YouTubeを1時間見たあと「自分は何を見ていたんだろう」と思ったとき。

**最初に刺さる一文**
「あなたは半年間で、◯◯の動画を◯本見ています。カレンダーには来年度から年間52日の空白が入ります。」

## 5. 提供価値

気づきではなく、**時間とお金を先に確保した未来が1つできること**。

## 6. 体験の流れ

1. **空白を見せる** — カレンダー・スクリーンタイムから「すでに年間◯時間の空白がある」と提示
2. **関心を掘り出す** — 記録から、頼まれてもいないのに見ているものを抽出し「実は◯◯に興味がある」と突きつける
3. **値札をつける** — 「10年後にそれを週3日やるなら、初期費用◯円、月◯円、週◯時間」
4. **予約する** — 「今の余った1日と月◯円を、この未来に予約しますか？」

資産をどう作るかは本人の仕事。アプリは値札を出すまで。

## 7. 入力

方針：**本人が意図せず残した記録**を使う。願望は聞かない。

| 種類 | 例 | 読み取るもの |
|---|---|---|
| 視聴・閲覧 | YouTube / TikTok履歴、Amazon閲覧 | 関心 |
| 予定 | Googleカレンダー | 空白の量と時期 |
| 会話 | Slack | 仕事に吸われている時間、口に出した願望 |
| 位置 | Googleマップ保存 | 関心 |

デモでは2〜3種類に絞る（候補：YouTube履歴 + Googleカレンダー）。

## 8. 出力

- 空白の可視化（年間◯時間 / 年間◯日）
- 関心の提示（根拠となる記録つき）
- 値札つきの10年後の生活
- 予約（形式は未決）

## 9. AIの役割

記録 → 関心 → 値札つき未来への翻訳、の1箇所に集中させる。
オプション：賛成役ではなく反対役（「それでも予約しますか？」）。

## 10. 未決事項

- 予約の出力形式（カレンダー登録 / 宣言の共有 / 10年後の自分からの手紙）
- 報酬設計（予約した額を確保できた月に何が起きるか）
- 記録の取り込み方法（Googleテイクアウト / スクショ / エクスポート）
- デモで使う入力の最終選定
