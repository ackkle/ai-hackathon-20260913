## 誰の、どんな困りごとを、どう変える作品ですか？

```
対象は、自分で選んだわけではないのに時間が空いてしまった人です。AIによる業務の減少、週休3日、定年、就活の終了。やる気がないのではなく、やる気を仕事に使い切ってきたので、空いた時間に何をしたいかが自分でも分からない。リザーブマシンは、その曖昧な気持ちを聞き取り、日時の入った1枚の「予約票」に変えます。今回動くのは、最初の1日の日時を決めて予約票を出し、やってみた後に振り返って次の一歩を決めるまでの流れです。
```

## 「10年後のあたりまえ」と、どうつながりますか？

```
10年後は、空いた時間が特別な事件ではなく全員の前提になっていて、「その時間で何をするか」を一緒に考えてくれる相手がいることが、あたりまえになっていると考えています。これは構想で、今回実装したのは、10年後の暮らしから今週の1件まで降りてくる画面の流れと、そのうち日時決定・予約票・振り返り・次の一歩の4画面です。
```

## AIを何に使い、どのように役立ちましたか？

```
制作中は、3人が別々に書いたMVP仕様書3本をClaude Code（Claude Opus 5）に読ませ、矛盾点を10項目に洗い出させました。そのうえで「10年後と1年後のどちらを軸にするか」「反対役を入れるか」といった判断は人間が決め、決めた結果を1本の正式仕様に書き戻させています。実装もIssue単位でClaude Codeに任せ、レビューとマージは必ず別の人間が行いました。

作品の中でもAIを使います。願いの言い換え、追加の質問、逆算ツリー、次の一歩の提案がAIの担当です。今日の公開版はモック応答で動かしていて、本物の呼び出しはサーバー側だけに置き、出力をzodスキーマで検証し、人を評価する言葉や断言が混ざっていないかを検査してから画面に出します。
```
